Run multi-step knowledge work across specialist agents, with a person approving every handoff.

The problem

  • AI output is a black box, with no visible sources or checks
  • One-pass answers let errors through
  • Managers cannot see or approve what the AI did
  • Prompts are rewritten by hand every time

How GlassHouse responds

  • Each agent shows its steps and sources
  • A dedicated Fact-Checker blocks unsupported claims
  • Approve, edit or send back at every stage
  • Any workflow can be saved as a template

Agent roster

  • Researcher: gathers sources and key facts
  • Writer: drafts from approved research
  • Fact-Checker: verifies claims against sources
  • Reviewer: checks tone, clarity and completeness
  • Triager and Summarizer: classify and condense
